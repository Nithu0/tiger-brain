# 00-claude-inbox — folder convention

Claude's write zone for session notes, captures, and synthesis. Operator reviews here in Obsidian; interesting items get promoted to proper notes or repo docs.

## Naming

`<project>/<YYYY-MM-DD>-<slug>.md`

Examples:
- `nexus/2026-05-08-orb-range-anomaly.md`
- `thesis/2026-05-08-electrolyte-conductivity-pattern.md`

## Lifecycle

Inbox → operator review → `_promote-candidates/` → repo `docs/memory/promoted/`. Inbox auto-archives after 30 days into `90-archive/inbox/<YYYY-MM>/`. See [[Workflows-MOC]] → Promote-Inbox-To-Repo.
