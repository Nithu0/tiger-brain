# 00-claude-inbox

Claude WRITE zone. New thoughts, captures, and synthesis land here as dated markdown notes.

## Naming

`<project>/<YYYY-MM-DD>-<slug>.md`

Examples:
- `nexus/2026-05-08-orb-range-anomaly.md`
- `thesis/2026-05-08-electrolyte-conductivity-pattern.md`

## Lifecycle

1. Claude writes a thought here
2. Operator reviews in Obsidian
3. Worthy notes move to `_promote-candidates/`
4. Operator (or Claude with explicit "OK kjør") promotes polished version to repo docs
5. Inbox entries auto-archived after 30 days into `90-archive/inbox/<YYYY-MM>/`

## Subfolders

- `nexus/` — Nexus trading firm thoughts
- `thesis/` — Master's thesis (battery electrolyte) thoughts

Add new project subfolders as needed.
