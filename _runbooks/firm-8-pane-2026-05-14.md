# firm 8-pane runbook (2026-05-14)

Operativ runbook for v2 av `firm`-launcheren: 8 Claude-paner fordelt på 6 prosjekter (workspace, nexus, master-oppgave, AS, søking fulltid, personlig).

Erstatter den gamle distribusjonen i [[firm-launcher]] (som hadde battery-1 + scratch og bare 3 prosjekter aktive). Den gamle filen er beholdt som historisk referanse.

## 1. Formål

Én keystroke (`firm`) bringer hele 6-prosjekts-teamet online i ett Windows Terminal-vindu med 8 paner. Hver pane er en uavhengig Claude-sesjon med sin egen `FIRM_ROLE`, `FIRM_PROJECT`, cwd og rolle-farge. Felles koordinering går via firm-bus (`~/Obsidian/Brain/00-firm-bus/`).

Mål: én operatør, 8 Claude-er i parallell, ingen kontekst-leakage på tvers av prosjekter.

## 2. Forhåndskrav

- **firm-launcher v2** installert (Agent A's leveranse i `/home/nithu/code/_bin/`).
  - `firm-tab-init.sh` (per-pane init — standalone).
  - `firm-wt-split.sh` (8-pane split-view, ny layout med 6 prosjekter).
  - `firm-wt-tabs.sh`, `firm-zellij.sh` (fallbacks).
- **`statusLine`** virker i Claude CLI (rolle/prosjekt synlig i statuslinje, ikke bare PS1).
- Windows Terminal tilgjengelig fra WSL (`/mnt/c/Users/nithu/AppData/Local/Microsoft/WindowsApps/wt.exe`).
- Claude CLI installert via NVM (`/home/nithu/.nvm/versions/node/*/bin/claude`).
- `~/Obsidian/Brain/00-firm-bus/` finnes (auto-opprettes hvis ikke).
- Hver prosjekt-cwd finnes:
  - `~/code` (workspace)
  - `~/code/ai-assistent` (nexus)
  - `~/code/Master-oppgave` (master)
  - `~/code/AS` (AS)
  - `~/code/soking-fulltid` (søking)
  - `~/code/personlig` (personlig)

## 3. Hvordan starte

```bash
firm                    # default — alias for firm-wt-split.sh
# eller direkte:
bash /home/nithu/code/_bin/firm-wt-split.sh
```

Tørr-kjør først hvis du er usikker:

```bash
firm --dry-run          # printer wt.exe argv uten å åpne vinduet
```

Fallbacks:

| Kommando | Effekt |
|---|---|
| `firmt` | 8 tabs i 1 WT-vindu (hvis split-view kjennes trang) |
| `firmz` | zellij-layout `ai-assistent/.zellij/layouts/firm8.kdl` |
| `nx` | alias for `firm` |

`firm!` virker ikke (bash history-expansion). Bruk `firm` eller `nx`.

## 5. Hva hver pane gjør (per-rolle dypdykk)

### Workspace (code-1, code-2)

- Cross-repo refactor, brain hygiene, runbook-skriving.
- Eier ingen domene-strategi; dispatcher kun.
- Default-mode: parallelle subagents (se [[Runbook-Multi-Agent-Dispatch]]).

### Nexus (ai-1, ai-2)

- ai-1: drift + phase-status + calibration. Eier `docs/ops/phase-status.md` updates.
- ai-2: review + audit + strategi-proposals. Eier `docs/audits/` og `docs/strategy/proposals/`.
- Begge: ingen live-flip uten "OK kjør" fra operatør.

### Master-oppgave (thesis-1)

- Kapittel-drafting i `Master-oppgave/` (LaTeX/Overleaf).
- Figurer/resultater hentes fra `battery-electrolyte-predictor/`.
- Auto-push hook aktiv kun for `Master-oppgave/` (se memory `reference_autopush.md`).

### AS (as-1)

- Eier `06-AS/`-mappen i brain og `~/code/AS/`.
- Regnskap, inntekt, fakturering, MVA, årsoppgjør.
- Ingen krysspollinering med Nexus eller masteroppgave-økonomi.

### Søking fulltid (soking-1)

- Eier `~/code/soking-fulltid/` og career-MOC.
- Job-scrape, søknader, intervju-prep, CV-versjoner.
- Eksisterende filer i `04-career/` (`Active-Job-Search-MOC`, `Job-Scrape-Strategy`, `Interview-Prep-Workflow`) eies av denne rollen.

### Personlig (personal-1)

- Eier `07-personlig/`-mappen.
- Effektivitet, mat, trening, søvn, vaner.
- Skriver IKKE til andre prosjekters mapper.

## 6. Koordinering — firm-bus protokoll

Felles meldingsbuss ligger i `~/Obsidian/Brain/00-firm-bus/`.

### Tre regler

1. **Les før du skriver** — les `inbox/$FIRM_ROLE.md` + siste 30 linjer av `feed.md` før ikke-trivielt arbeid.
2. **Handoff via inbox** — skriv en datostemplet markdown-blokk til `inbox/<peer-role>.md`:
   ```
   ## 2026-05-14 14:32 — from ai-1
   Trenger gjennomgang av siste calibration-run. Se docs/ops/phase-status.md.
   ```
3. **Annonser ferdig** — append `done: <one-liner>` til `feed.md` når en chunk er ferdig.

### Hvor skrive hva

| Hva | Hvor |
|---|---|
| En-linjers status / chunk done | `00-firm-bus/feed.md` |
| Handoff til en annen rolle | `00-firm-bus/inbox/<peer-role>.md` |
| Lange rapporter / verifikasjonslogger | `00-claude-inbox/<project>/` |
| Day-end handoff | `handoffs/` |
| Beslutninger | `_decisions/` (kun owner-agent skriver) |

### Anti-patterns

- Ikke skriv lange tråder i `feed.md` — den skal være tail-bar.
- Ikke skriv til en peer's inbox uten dato-stempel og fra-rolle.
- Ikke kryss-poller prosjekt-kontekst (Nexus → AS, master → personlig, osv.).

## 7. Når en pane skal slå seg av

`FIRM_TAB_OPENED_AT` er ISO-timestamp satt ved pane-init. Sjekk i pane:

```bash
echo $FIRM_TAB_OPENED_AT
# Hvis eldre enn ~8 timer, vurder ny pane for å få frisk kontekst.
```

Tegn på at en pane bør startes på nytt:

- Claude-konteksten er kompaktert flere ganger og svarer treigt.
- Pane har sittet idle > 4 timer og kontekst er stale.
- `feed.md` viser at en peer venter på handoff fra denne rollen og rollen ikke har svart.

Graceful shutdown: `exit` eller `Ctrl+D` i pane. Eller lukk hele vinduet og `firm` igjen.

## 8. Troubleshooting

| Symptom | Årsak | Fix |
|---|---|---|
| `wt.exe error 0x80070002` | Newline/heredoc i wt-argv | Bruk `firm --dry-run` for å inspisere argv. Alle paner går nå via `firm-tab-init.sh`. |
| `bash: <path> <args>: No such file or directory` (path med spaces) | Inner cmd ble sitert til `bash -lic` | Hold inner cmd UNQUOTED — verdier har ingen spaces. Se `firm-tab-init.sh` WARNING-kommentar. |
| `claude: command not found` i pane | NVM PATH ikke lastet | Sørg for `bash -lic` (login + interactive shell). |
| `wt.exe: command not found` fra WSL | WT ikke installert | Verifiser at `/mnt/c/Users/nithu/AppData/Local/Microsoft/WindowsApps/wt.exe` finnes. |
| `firm!` feiler | Bash history-expansion | Bruk `firm` eller `nx`. |
| Pane åpner i feil cwd | `firm-tab-init.sh` har feil mapping | Sjekk `roster.md` + scriptets case-statement. |
| Pane mangler rolle-farge i prompt | `nexus-bashrc.sh` ikke sourced | Sjekk at `.bashrc` sourcer `nexus-bashrc.sh`. |
| To paner skriver til samme inbox samtidig | Ikke en feil — bare merge | Begge meldinger overlever, dato-stempel skiller dem. |
| Zellij copy/paste klønete | Default mouse-mode i zellij | `Ctrl+S` for scroll-mode, `v` velger, `y` yanker. |
