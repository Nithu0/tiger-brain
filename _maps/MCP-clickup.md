# MCP-clickup

ClickUp MCP — operator's task / list / doc / time-tracking workspace. Tool names: `mcp__claude_ai_ClickUp__clickup_*`.

## What it enables
- Read & write tasks, lists, folders, comments, time entries.
- Search workspace, find members, resolve assignees.
- Create / update documents, manage tags & dependencies.
- Send chat messages & read channels.

## When to reach for it
- Operator says "legg det inn i ClickUp" or asks status on a tracked task.
- Building a checklist of operator-owned followups that should live outside the repo.
- Time-tracking on a specific bounded task operator wants logged.

## Boundaries
- Don't create tasks unprompted — clutter risk.
- Confirm list/folder targets before bulk operations.
