# E-post til DFØ (utkast) — vilkår og lisens for Doffin Public API

Til: [DFØ, Doffin-forvaltning: finn riktig adresse på anskaffelser.no / dof-notices-prod-api.developer.azure-api.net. Notices-API-kontakten (ingunn.ostrem@dfo.no) gjelder innsending og er neppe riktig mottaker.]
Fra: Nithusan Kukaraja, Solarconsulting AS (org.nr. 931949837)
Emne: Vilkår og lisens for bruk av Doffin Public API

> Hei,
>
> Solarconsulting AS utvikler et verktøy som hjelper oss og andre leverandører å finne og vurdere offentlige anskaffelser. Vi henter i dag kunngjøringer fra Doffin Public API (`/public/v2/search`) med abonnementsnøkkel.
>
> Vi finner ikke bruksvilkår eller lisens for API-et. Produktet i utviklerportalen har ingen vilkår oppgitt. Vi ønsker å bruke dataene riktig, og har derfor fire spørsmål:
>
> 1. Hvilken lisens gjelder for data hentet via Doffin Public API (`search` og `download`)? Gjelder CC BY 4.0, som brukes for DFØs månedlige datasett på data.norge.no, også for API-et?
> 2. Kan vi lagre kunngjøringene og vise utdrag og analyser av dem til våre kunder i et kommersielt verktøy, med kildehenvisning til Doffin?
> 3. Er det i orden å bruke API-et bak doffin.no sitt eget webgrensesnitt (`api.doffin.no/webclient/...`)? Eller ønsker dere at all maskinell bruk går via Public API?
> 4. Gjelder grensene i utviklerportalen (30 søk og 10 nedlastinger per minutt), eller er det andre grenser vi bør forholde oss til ved historisk innhenting?
>
> Takk for hjelpen.
