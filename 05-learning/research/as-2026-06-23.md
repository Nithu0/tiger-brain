# AS-research 2026-06-23 — regnskap-automasjon, dokument-AI, refinansiering

Web/video/forum-sveip for AS-prosjektet (norsk regnskap-automasjon + RefiPrep case-prep + bilag-OCR/lokal LLM doc-extraction). Kun offentlige tips/verktøy — ingen klient/PII-data berørt. Mappet mot **RefiPrep** (managed-ai-ops produktet, Pål først) og **AS** (eget regnskap/inntekt).

Ærlighet om kilder: dette er en **discovery + summary-sveip**, ikke transcript-mining. Av video-kilder ga kun ÉN reell treff (Fiken offisiell "Mva enkelt forklart"), og den ble ikke transcript-uttrukket — bare tittel/beskrivelse. Resten av video-laget er discovery-only (Fiken offisielle kanal + webinarer). Det norske YouTube-laget for *teknisk* regnskap-automasjon er tynt; de beste tekniske kildene er GitHub-repos + engelske OCR/LLM-benchmarks. Norske forum ga lite (hardware.no/diskusjon.no ikke indeksert på disse søkene); enkeltpersonforetak.no + Skatteetaten + regnskapsfører-blogger dekket ENK-praksis.

## TL;DR — Top 5 adopt-now (for AS + RefiPrep)

1. **Fiken API + read-only MCP-mønster** (`heim/fiken-read-only-mcp`, 61 GET-tools, serial request-queue mot Fikens 1-concurrent rate-limit). Adopter MCP-mønsteret for trygg AI-tilgang til regnskapsdata. **WHY:** lar en agent lese hele regnskapet uten muterings-risiko — perfekt for vår "diagnose = read-only"-policy. **CONF: høy.**
2. **PaddleOCR (PP-StructureV3 / PaddleOCR-VL) som default OCR for bilag.** Best på tabell-tunge fakturaer + 100+ språk + layout-analyse out-of-the-box; 0.9B VLM kjører lokalt. **WHY:** norske fakturaer = linjeposter + MVA-tabeller; PaddleOCR slår Tesseract på akkurat dette og holder PII lokalt (ingen Vast for 24/7-last). **CONF: høy** (OmniDocBench 96.33, ledende 2026).
3. **TaxHacker-arkitekturen som blåkopi** (`vas3k/TaxHacker`, 6.1k stars, MIT): self-hosted, LLM-agnostisk (OpenAI/Gemini/Mistral/**lokal via Ollama/vLLM**), custom prompts per felt, PostgreSQL, CSV-eksport for regnskapsfører. **WHY:** dette ER produktet vi vil bygge for klienter — ikke bygg fra null, kopier deres pipeline (PDF→Ghostscript/GraphicsMagick→VLM→strukturert JSON). **CONF: høy.**
4. **RefiPrep dok-sjekkliste + gjeldsregister-triks** som første konkrete RefiPrep-leveranse. Bankens 3 avslagskriterier: belåningsgrad (maks 90% nedbetaling / 60% ramme), gjeldsgrad (total gjeld/bruttoinntekt), betjeningsevne (stress-test ved renteøkning). **Triks: logg inn på gjeldsregisteret og lukk ubrukte kredittrammer FØR søknad — hever søknaden uten å nedbetale faktisk gjeld.** **WHY:** dette er kjernen i RefiPreps verdiløfte (case-prep som hever godkjenningsrate). **CONF: høy** (Fondi/Bankvett/Dinero samstemte).
5. **"Norwegian-accounting-automation"-skill som referanse-workflow** (`ahdrage/...`): Gmail-søk→last ned faktura-PDF→bokfør i Fiken med riktig betalingskonto→fest PDF→match kortbevegelser (Folio)→MVA-håndtering (SaaS/utenlandske varer). **WHY:** ferdig kart over hele AS-bilag-flyten ende-til-ende; vi kan adoptere stegene og MVA-mønstrene direkte. **CONF: middels** (uverifisert kvalitet, "guidance not advice", men strukturen er solid).

## A. Document-AI / OCR / lokal LLM (kjernen i produktet)

- **PaddleOCR (PP-StructureV3, PaddleOCR-VL 0.9B)** — best open-source for tabell-tunge/flerspråklige fakturaer; layout+tabell-gjenkjenning innebygd; 109 språk; OmniDocBench 96.33 (#1 2026). *Map: default bilag-OCR-motor, lokal.* **NEW — adopter. CONF: høy.**
- **docling (IBM)** — strukturert dok-forståelse (tabeller, lese-rekkefølge, hierarki) til RAG; PDF/DOCX/PPTX/XLSX/HTML/audio; LlamaIndex/LangChain-integrasjon. SVAKHET: markdown-first, sliter med skannet/håndskrift. *Map: bruk for RAG over regnskaps-dokumenter, IKKE som primær bilag-felt-ekstraksjon.* **NEW — nisje. CONF: høy.**
- **OCRmyPDF** — legger OCR-tekstlag på skannede PDF-er (gjør dem søkbare). *Map: forsteg før felt-ekstraksjon på skannede bilag.* **NEW — billig vinst. CONF: middels.**
- **Surya / Marker** — layout-tung OCR + PDF→markdown; GPU/CPU/MPS. *Map: alternativ til docling for ren markdown-konvertering.* **CONF: middels.**
- **Qwen2.5-VL / DeepSeek-VL2 / GLM-4.5V** — vision-LLM direkte på faktura-bilde→JSON; håndterer usette format/språk. Krever GPU, sekunder/side. *Map: lokal VLM-felt-ekstraksjon for varierte leverandør-format; kandidat for on-prem node (~Aug 2026), IKKE Vast for 24/7.* **NEW — adopter på node. CONF: høy.**
- **invoice2data** — template-basert, bra for <10 stabile leverandører; vedlikehold skalerer lineært med leverandør-antall. *Map: quick-win for AS' egne faste leverandører før vi har VLM-pipeline.* **CONF: middels.**
- **To-pipeline-valg (gjennomgående råd):** (1) OCR→LLM (Tesseract/PaddleOCR→Ollama liten modell) eller (2) Vision-LLM direkte. Avgjørende spørsmål: *"hvilken stack etterlater minst custom-arbeid etter OCR"* — ikke hvem leser tegn best isolert. **CONF: høy.**

## B. Fiken-økosystem (norsk-spesifikt, høy verdi)

- **`heim/fiken-read-only-mcp`** — 61 GET-tools, hele Fiken v2 read-API, `companySlug` multi-company, `FIKEN_API_TOKEN`, serial queue mot rate-limit (1 concurrent/user). *Map: trygg AI-lesetilgang; matcher vår read-only-diagnose-policy.* **NEW — adopter direkte. CONF: høy.**
- **Fiken MCP-skrive-servere** (`Proviscale/fiken-mcp-server`, `gronnmann/fiken-mcp`, `Casper0301`, `vfaergestad`, `kradalby/fiken-go`) — fakturaer/kontakter/journal-poster via agent. *Map: skrive-laget når vi vil at agenten skal bokføre — operatør-gated.* **NEW — vurder, gated. CONF: middels.**
- **`jakoblind/fiken-cli`** (Go) — script-vennlig CLI for SMB-bokføring. *Map: rask CLI-automasjon i firm-scripts.* **CONF: middels.**
- **`samletnorge/adb_fiken`** (Python) — auto-prosesserer + laster opp kvittering-bilder til Fiken via ADB/bilde-prosessering. *Map: mønster for batch-bilag-opplasting.* **CONF: lav-middels** (nisje, ADB-spesifikk).
- **`bjerkio/fiken-js`** + **`audunru/fiken-api-php-client`** (arkivert) — språk-klienter; swagger.json finnes i bjerkio-repoet. *Map: referanse for API-endepunkter (bilag-vedlegg: `attachToPayment`/`attachToSale`).* **CONF: høy** (swagger = sannhet).
- **`ahdrage/norwegian-accounting-automation`** — agent-skill: Gmail→Fiken→Folio ende-til-ende-flyt, MVA-mønstre (SaaS/lokal/utenlandske varer), dedup på samme-dato-samme-beløp. *Map: referanse-workflow for hele AS-bilagsflyten.* **NEW — adopter struktur. CONF: middels.**
- **Fiken API capabilities** (fra swagger): fakturaer, bilag/vedlegg-opplasting (multipart), kontakter, kontoer, salg/kjøp, prosjekter, tidsregistrering. Rate-limit 1 concurrent/user. Token via Fiken-innstillinger. **CONF: høy.**

## C. Norsk regnskap-praksis / ENK / AS (kontekst, mest "already-known")

- **ENK-terskler:** >50 000 kr/år → bokføringsplikt + næringsspesifikasjon; <600 transaksjoner/år → regneark-mal tillatt. Forskuddsskatt. *Map: AS' egen compliance-baseline.* **ALREADY DO. CONF: høy** (Skatteetaten).
- **MVA-kjerne:** registreringsplikt >50k; MVA er ikke kostnad (samler inn for staten, trekker fra inngående). Bilag MÅ festes for å få MVA-fradrag. *Map: kjerne-regel i enhver auto-bokførings-validering.* **ALREADY DO. CONF: høy.**
- **Norske AI-regnskap-aktører (konkurrenter/benchmark):** Conta "Kaia" (auto-bilag-tolk, konto-forslag, MVA-avvik-varsel), Catacloud (auto-bilagsgjenkjenning + avviksanalyse), Snapbooks (AI + regnskapsfører-kontroll), Tripletex/Fiken (innebygd OCR+ML, 95-98% nøyaktighet). Byråer rapporterer 15-20 t/regnskapsfører/mnd spart. *Map: dette er hva RefiPrep/managed-ai-ops konkurrerer mot — vår edge = vi bygger+drifter dypt for klienten, ikke selvbetjent SaaS.* **NEW intel. CONF: middels** (markedsføringstall, ta 95-98% med klype salt).

## D. Refinansiering / RefiPrep case-prep (direkte produkt-input)

- **3 avslagskriterier banken vurderer samlet:** belåningsgrad (maks 90% nedbetalingslån m/sikkerhet, 60% kredittramme), gjeldsgrad (total gjeld/bruttoinntekt — inkl. studielån, billån, kreditt + ubrukte rammer), betjeningsevne (stress-test ved renteøkning). **NEW — RefiPrep kjernemodell. CONF: høy.**
- **Gjeldsregister-triks:** lukk ubrukte kredittrammer før søknad → bedre søknad uten faktisk nedbetaling. **NEW — konkret RefiPrep-leveranse. CONF: høy.**
- **Dok-sjekkliste:** siste lønnsslipper, siste skattemelding, kontoutskrifter (lønnskonto + kredittkonto siste mnd), full gjeldsoversikt m/opprinnelig løpetid, dokumentasjon på bonus/provisjon/leie/trygd, boligverdi. Fersk dok + forklaring ved nylige endringer. **NEW — RefiPrep dok-innsamlings-mal. CONF: høy.**
- **Banker som tar betalingsanmerkning m/boligsikkerhet:** Nordax, Kraft Bank, Bank 2, Bluestep, MyBank, Instabank, Svea, Balansebank, Resurs, BN Bank. *Map: RefiPrep bank-matching-liste for vanskelige caser.* **NEW. CONF: middels.**
- **Tidslinje:** 3-10 virkedager søknad→utbetaling; raskere ved inkasso/tvangssalg. **CONF: middels.**

## Allerede vs NYTT

**Already do / kjent:** ENK/MVA-compliance-regler, at Fiken har API, at lokal LLM er veien (PII→ikke Vast 24/7→on-prem ~Aug).
