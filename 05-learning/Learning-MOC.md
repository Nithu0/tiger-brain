# Learning-MOC

Hub for active learning. Distinct from [[Thesis-MOC]] (formal academic output) and [[Nexus-MOC]] (production code) — this domain is about the inputs feeding both.

## What lives here

- Currently reading (books, papers, courses)
- Want-to-learn queue
- Topic notes — ML, trading systems, AI agents — that span multiple domains
- Books + papers log
- Anything that doesn't fit a single deliverable yet

## Sub-topics

- [[Currently-Reading]] — active queue.
- [[Want-To-Learn]] — backlog, ranked.
- [[Notes-On-ML]] — machine learning notes; cross-link to [[Thesis-MOC]].
- [[Notes-On-Trading-Systems]] — trading-systems theory; cross-link to [[Nexus-MOC]].
- [[Notes-On-AI-Agents]] — agentic systems; cross-link to [[Tools-MOC]].
- [[Books-And-Papers]] — log of titles read with one-line takeaways.

## Cross-domain links

- [[Thesis-MOC]] — formal ML output.
- [[Nexus-MOC]] — operator's applied trading-systems work.
- [[Tools-MOC]] — concrete agent + tooling capabilities.
- [[Career-MOC]] → [[Skills-To-Develop]] — the why behind what gets learned.

## Conventions

- One paper / book = one entry in [[Books-And-Papers]] with date + 1-line takeaway. Detail goes in topic notes.
- Stub notes start with `> Stub — operator to fill`.
- Re-link aggressively — a note isolated in Graph View is a smell.
