# Career-MOC

Hub for the career domain. Where operator is now, where they're heading, what skills + relationships are required to get there.

- Snapshot of the current role / setup
- Skills inventory + skills-to-develop

- Long-term vision (5–10 year horizon)
- Resume / CV state — what's current, what needs updating
- Job-search status — only relevant when actively searching
