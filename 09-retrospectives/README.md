## Purpose

This folder holds per-ISO-week retrospectives that roll up the week's commits (across repos), decisions, completed tasks, blocked/carried items, and surfaced lessons. The BrainOrchestrator weekly trigger runs Sunday 22:00 local time and generates a draft from the prior week's signals (handoffs/, _decisions/, 10-tasks/_done/, firm-bus feed.md, project session-summaries, per-repo `git log --since='7 days ago'`). Operator reviews + finalizes. This folder is forward-looking ONLY (from 2026-W22 onward) — existing `handoffs/` and scattered session-summaries are NOT moved. Over time, retrospectives become the canonical week-view; raw signals stay where they are.

## Subfolders

None at present.

## Naming convention

`YYYY-WNN.md` (ISO 8601 week) — e.g. `2026-W22.md`, `2026-W23.md`. ISO weeks start Monday; week 1 contains the first Thursday of the year.

## Authoritative schema (10 sections)

This is the **authoritative schema** for all retrospectives in this folder from 2026-W22 onward. The template lives at [[00-templates/retrospective]]; the first usage is [[2026-W22]]. Any deviation should be motivated explicitly in the file.

Sections, in order:

1. **Summary** — 1 paragraph, filled at end of week (running notes OK during)
2. **Major events** — bullet list, append throughout the week, ISO timestamps + commit SHAs where they exist; sources: `00-firm-bus/feed.md`, `_decisions/`, `10-tasks/_done/`, `handoffs/`
3. **Commits across repos** — top-level heading with one sub-heading per repo:
   - `### command-center` — `git -C /home/nithu/code/command-center log --oneline --since='7 days ago'`
   - `### ai-assistent (Nexus)` — `git -C /home/nithu/code/ai-assistent log --oneline --since='7 days ago'`
   - `### tiger-brain (Obsidian)` — `git -C /home/nithu/Obsidian/Brain log --oneline --since='7 days ago'`
   - `### Master-oppgave + battery-electrolyte-predictor (thesis)` — git logs for both thesis repos
   - Add additional repos as sub-headings when relevant
4. **Decisions made (from _decisions/)** — wikilinks to new files in `_decisions/` this week, plus cross-links to decisions that landed elsewhere (e.g. `08-system-architecture/`)
5. **Tasks completed (from 10-tasks/_done/)** — wikilinks to task files moved into `_done/` this week
6. **Lessons learned** — 2–5 bullets, what surprised us, what to remember; filled at end of week
7. **Open from last week (carried over)** — unfinished items inherited from prior week
8. **Plan for next week (WN+1)** — seeded mid-week, refined Sunday
9. **Operator notes** — operator-only space; Claude should not auto-edit

(Count is 9 explicit sections + an implicit "scope note" callout at the top if the week boundary needs clarification — see [[2026-W22]] for an example. The shorthand "10-section schema" refers to Summary + 8 body sections + Operator notes; the folder is colloquially "10-section" to distinguish from the deprecated 6-section schema, see Changelog below.)

## Frontmatter convention

Required fields (matches [[2026-W22]] + [[00-templates/retrospective]]):

- `title` — `Retrospective YYYY-WNN`
- `type` — `retrospective`
- `week` — ISO week (e.g. `2026-W22`)
- `date_range` — `YYYY-MM-DD to YYYY-MM-DD` (Monday → Sunday)
- `created` — `YYYY-MM-DD` (date file was first written)
- `status` — `in-progress (week-current; finalized end-of-week)` while live; `finalized YYYY-MM-DD` once operator signs off
- `related` — wikilinks to related notes (decisions, MOCs, plan-docs)
- `tags` — `[retrospective, weekly, wNN]`

## Workflow

1. Sunday 22:00 — BrainOrchestrator weekly trigger fires
2. Orchestrator scans `handoffs/`, `_decisions/`, `10-tasks/_done/`, `00-firm-bus/feed.md`, and per-repo `git log --since='7 days ago'` for the ISO week
3. Drafts `YYYY-WNN.md` from [[00-templates/retrospective]] with all 9 sections seeded
4. Operator reviews Monday morning, edits, sets `status: finalized YYYY-MM-DD`
5. Retrospective becomes canonical week-view; raw signals stay in place

## Anti-patterns

- Moving existing `handoffs/` or session-summaries into this folder (additive only)
- Manual retros without orchestrator draft (defeats automation; only acceptable for backfilled weeks like a manual `2026-W21.md`)
- Cross-week retros (one week = one file; multi-week roll-ups go elsewhere)
- Deleting unfinalized drafts (operator may not have reviewed yet)
- Reverting to the deprecated 6-section schema (Highlights/Decisions/Completed/Blocked/Lessons/Next) — see Changelog
